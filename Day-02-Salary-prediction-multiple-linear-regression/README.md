# 💰 Salary Prediction using Multiple Linear Regression

## Objective

Predict an employee's salary using:

- Age
- Gender
- Education Level
- Job Title
- Years of Experience

## Dataset

Kaggle Salary Dataset

## Machine Learning

Multiple Linear Regression

## Preprocessing

- Missing-value handling
- Duplicate checking
- Category standardization
- Rare-category handling
- One-Hot Encoding

## Evaluation

- MAE
- MSE
- RMSE
- R²

## Model Pipeline

Data
↓
Preprocessing
↓
One-Hot Encoding
↓
Multiple Linear Regression
↓
Salary Prediction
