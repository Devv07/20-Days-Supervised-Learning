# ⚡ Day 7 — Electricity Consumption Prediction using Decision Tree Regression

## 📌 Project Overview

This project is part of my **20-Day Supervised Learning Challenge**.

The challenge is divided into:

- 🔟 10 Regression Projects
- 🔟 10 Classification Projects

For Day 7, I implemented **Decision Tree Regression** to predict monthly electricity consumption in kWh.

The model learns relationships between building characteristics, environmental conditions, appliance usage, and previous electricity consumption to predict future monthly consumption.

---

## 🎯 Objective

Build a machine learning regression model that predicts:

**Monthly Electricity Consumption (kWh)**

using features related to:

- Building characteristics
- Occupancy
- Appliance usage
- Environmental conditions
- Previous electricity consumption
- Building type
- Season
- Solar panel availability

---

## 📊 Dataset

The dataset contains **2,000 records** after data cleaning.

### Target Variable

```text
monthly_consumption_kwh
```
